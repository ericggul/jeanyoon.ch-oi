# Terminal aesthetic references

Collected for the [`/v2` portfolio study](https://jeanyoon-ch-oi.vercel.app/v2).

These are optional visual references, not design requirements or instructions to copy their layouts or behavior. Links and descriptions were checked on 2026-09-25; live sites may change.

| Site | Link | Terminal element |
| --- | --- | --- |
| Ha Huy | [hahuy.site](https://hahuy.site/) | A shell prompt and cursor form the homepage's main interface. |
| LMNTS | [lmnts.me](https://lmnts.me/) | ASCII lettering, `ls -la` output, file permissions, and command prompts structure the page. |
| Wallscreet | [wallscreet.discorover.com](https://wallscreet.discorover.com/) | An ASCII masthead and commands such as `whoami`, `cat`, and `cd` organize the homepage. |
| Souleymane Sy | [terminal portfolio](https://terminal-portfolio-website-xi.vercel.app/) | An interactive terminal presents the portfolio through typed commands. |
| Anshul Jagtap | [anshuljagtap.com](https://anshuljagtap.com/) | Shell commands label portfolio sections; the contact form references the `nano` editor. |
| Terminal Shop | [terminal.shop](https://www.terminal.shop/) | A non-portfolio site with sparse command-line presentation and `ssh terminal.shop` as a prominent entry point. |

[Midjourney](https://www.midjourney.com/) was mentioned as an earlier terminal-aesthetic reference. Its current homepage has changed, so this link does not preserve the earlier version's appearance.
