# Artwork migration sources

The four artwork modules use existing XD Lab text: English summaries, paragraphs, medium, creators, and venue come from `../xdlab-website/data/projects.json`. Video links were checked against the corresponding public XD Lab pages. `menuDescription` is a separate navigation preview.

Gallery files are named `1.webp` through `N.webp` in display order. Within each artwork, the selected installation views and artwork visuals were shuffled with a fixed seed, then interleaved so near-identical scenes do not run together. The displayed order is stable; another shuffle would require renumbering the files and data together. Duplicated or near-duplicated images were removed after visual comparison of the complete gallery sequence.

Large WebPs were recompressed only when the smaller file met a pixel-similarity gate against the existing image (SSIM at least 0.995 at unchanged dimensions, or 0.9975 at the site's 960-pixel display width for downscaled files). Originals that did not pass were copied without re-encoding. The supplied Drive folder and related Google Docs were reviewed as secondary sources; the Banpo-Xism Leonardo manuscript is still under review, so its unpublished prose was not copied into the site. The XD Lab and v3 repositories remain read-only migration sources.

Caption provenance: Banpo-Xism figure captions are concise adaptations of the author manuscript figure captions in `Documents/banpo-xism-leonardo/bridge/trusted-read-math-0811/document-text.md`; the finalised mathematical revision is not represented as a new published claim here. SoTA paper-figure captions describe the supplied author figure assets and draw on the draft figure text in `Documents/Downloads/SoTA_CHI__0718 (3).pdf`; they are not presented as verbatim captions from the published ACM version. Other image captions describe the visible photo or screen and are separate from accessibility alt text. The ≠ exhibition history comes from the work-specific `../portfolio-v3/components/custom-pages/Nonequality/index.tsx` list. The SoTA DIS Interactivity entry comes from the current CV at `public/cv/JeanyoonChoi_CV.pdf`.
